This end-to-end blueprint structures the transformation of the Barnes & Noble NOOK GlowLight Plus 7.8" (BNRV700 / Quill) into a dedicated, low-overhead Linux reading and productivity terminal.

It leverages Antigravity CLI (agy) to orchestrate host-side artifact generation, rootfs staging, and configuration patching while maintaining strict hardware safety boundaries.
Phase 0: Architecture & Hardware Target Definition
1. Hardware Manifest (target_specs.json)

The agent requires these exact hardware invariants across all configuration templates:

    SoC: NXP/Freescale i.MX6 SoloLite (MCIMX6L8DVN10AB), 1× Cortex-A9 @ 1.0 GHz.

    Display / EPDC: 7.8" E Ink Carta HD (ED078KC1), 1404 × 1872 @ 300 ppi, 16-bit bus, accessed via /dev/fb0 with NXP/Netronix ioctls.

    Touch Digitizer: Elan Microelectronics eKTH3676CAY (I²C, 30×40 matrix), Linux evdev node /dev/input/event1.

    Hardware Keys: 6-key matrix mapped to /dev/input/event0 (Power=116, Home=102, Side keys=191–194 / F9–F12).

    Wireless / BT: Realtek RTL8723DS (SDIO Wi-Fi via 8723ds.ko, BT 4.2 via UART ttymxc1).

    RAM / Storage: 1 GB LPDDR2/3, 8 GB eMMC (/dev/block/mmcblk0).

2. Runtime Topology

+-------------------------------------------------------------------------------+
| User Applications (Framebuffer & Terminal)                                    |

+-------------------------------------------------------------------------------+
| Kernel & Intercept Layer (Vendor Linux 3.0.35 nook_ntx_6sl)                   |
|  - init.rc hook at post-fs-data -> /data/boot_linux.sh -> chroot /data/linuxroot|
|  - Android Dalvik/ART, SurfaceFlinger, and Zygote bypassed entirely           |

Phase 5: Gated Deployment & Verification Steps

Run these manual verification steps once agy completes the payload generation:

    Test Boot (Zero Risk to Flash):
    Place device into fastboot mode via TWRP or key combinations. Run a tethered boot:
    Bash

    fastboot boot boot_linux.img

    Pass Criteria: The Nook boots through the kernel without a bootloop. If something fails, a hard reset boots back to stock.

    Deploy Rootfs via TWRP:
    Boot into TWRP recovery and push the payload:


adb shell "mkdir -p /data/linuxroot /data/syncthing/notes /data/books"
    adb push scripts/boot_linux.sh /data/boot_linux.sh
    adb shell "chmod 755 /data/boot_linux.sh"
    adb push build/deploy_payload.tar.gz /data/
    adb shell "tar -xzf /data/deploy_payload.tar.gz -C /data/linuxroot/"
    adb shell "rm /data/deploy_payload.tar.gz"

    Install Alpine Packages Inside Chroot:
    Execute a setup pass through ADB while still in TWRP:
    Bash

    adb shell
    chroot /data/linuxroot /bin/sh
    apk update
    apk add syncthing netsurf-framebuffer tslib font-dejavu dropbear curl ca-certificates
    exit

    Flash Permanent Kernel:
    Once verified, write the modified boot image:
    Bash

    fastboot flash boot boot_linux.img
    fastboot reboot

The device will boot directly into KOReader, leaving ~650 MB of contiguous RAM free, running Syncthing silently in the background, and providing an instant-launch path for NetSurf whenever lightweight web lookups are needed.
