The Frontlight Toggle Script (/opt/scripts/toggle_frontlight.sh)When the double-click fires, this script checks whether the LEDs are currently active. If on, it records the current level and sets brightness to 0. If off, it restores the previous brightness:Bash#!/bin/sh
STATE_FILE="/tmp/frontlight_saved_level"
SYS_COOL="/sys/class/backlight/backlight_cool/brightness"
SYS_WARM="/sys/class/backlight/backlight_warm/brightness"

CURRENT_COOL=$(cat "$SYS_COOL" 2>/dev/null || echo 0)

if [ "$CURRENT_COOL" -gt 0 ]; then
    # Light is currently ON -> Save current levels and turn OFF
    echo "$CURRENT_COOL" > "$STATE_FILE"
    echo 0 > "$SYS_COOL"
    echo 0 > "$SYS_WARM"
else
    # Light is currently OFF -> Restore previous level (or default to 32)
    RESTORE_VAL=32
    if [ -f "$STATE_FILE" ]; then
        RESTORE_VAL=$(cat "$STATE_FILE")
    fi
    echo "$RESTORE_VAL" > "$SYS_COOL"
fi
